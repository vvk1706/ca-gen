ZLINUX / WAS LIBERTY DEPLOYMENT NOTES
─────────────────────────────────────────────────────────────────────────────────

Target platforms:
  - IBM z16 / LinuxONE running native Linux (s390x)
  - z/OS Container Extensions (zCX) on z16
  - Red Hat OpenShift on IBM Z (OCP s390x)

Liberty base image:
  icr.io/appcafe/websphere-liberty:23.0.0.9-full-java11-openj9-ubi-s390x

JDK:
  IBM Semeru Runtime Certified Edition 11 (s390x / OpenJ9)

DB2 driver:
  db2jcc4.jar (Type 4) — mounted as shared library at
  /opt/ibm/wlp/usr/shared/resources/db2jcc/

CICS integration:
  CICS TS 6.x Liberty JVM Server (DLISLRTY)
  JVMPROFILE: DLISLRTY.jvmprofile (USS filesystem)
  Programs installed via: DFHCSDUP INSTALL GROUP(DLISGRP)
  DB2 attachment: DB2ENTRY(DLISDB2) → DB2ID(DLISDB)

Environment variables (override via K8s secrets):
  DB2_HOST, DB2_PORT, DB2_DBNAME, DB2_USER, DB2_PASSWORD
  DLIS_KEYSTORE_PASSWORD

Ports:
  9080 (HTTP), 9443 (HTTPS/TLS)

Build:
  cd java && ./build.sh          — Maven build (produces dlis.ear)
  ./build.sh docker              — Build s390x container image
  ./build.sh db2-deploy          — Run DDL against target DB2
  ./build.sh cics-install        — Reminder to submit DFHCSDUP batch job
