DLIS Documentation Comparison

Driver License Issuance System — docs/ (CA Gen model) vs mf/docs/ (hand-written COBOL/CICS implementation)

Yes — they document the same application. Both sets describe the Driver License Issuance System (DLIS): the same seven entities, the same 8-step sequential workflow (PE→EC→HC→PA→A2→AP→IS / RE), the same three license types (L/P/O), the same dual-authority approval with segregation of duties, and the same 10 screens accessed via an identical menu. The fundamental difference is abstraction level and technology layer: docs/ describes the CA Gen model-level design; mf/docs/ describes the hand-written COBOL/CICS artifact that either was generated from, inspired by, or is intended to be compared against that model.

3. Workflow / Business Logic — Agreements & Differences

Status code pipeline Identical

Both define the exact same eight states in the same order: PE → EC → HC → PA → A2 → AP → IS, with RE as a rejection terminal at any gate.

Status code A1 Minor conflict

docs/ (06-DATA-DICTIONARY)
Lists A1 as a valid APPLICATION-STATUS value: "Awaiting First Authority Approval". The workflow doc (02) notes it is a "display alias" only.
mf/docs/ (02-MF-DATA-MODEL)
DB2 CHECK constraint explicitly includes A1 as a permitted column value alongside A2. No mention of it being alias-only — it is a real DB2 constraint value.

Eligibility rules Identical

Both define identical minimum ages (L≥16, P≥17, O≥18) and prior-licence prerequisites for Probation and Open. Both use current-year minus DOB-year arithmetic.

History check rules Identical

Both define three fail conditions: active SU/DQ suspension, demerit total > 12, unpaid fines. The MF doc specifies a 50-row cursor buffer; docs/ does not.

Dual-authority segregation Identical

Both enforce: Level-1 approver must differ from Level-2 approver's AUTHORITY_NAME/APPROVAL-1-AUTHORITY. Both require the approver to hold the correct level and to be authorised for the licence type.

Licence number format Identical

Both define: LRN/PRB/OPN prefix + vehicle class + CANDIDATE_ID + APPLICATION_ID. Validity periods (1/2/5 years) are identical. Starting demerit balance of 12 is identical.

6. Deployment — Key Differences

docs/ — CA Gen deployment (07-DEPLOYMENT-GUIDE)
  • Load encyclopedia: entities → views → BFNs → ABs → screens → triggers (36 files)
  • CA Gen DDL generation from Design Toolset
  • CA Gen Application Generation (CICS/COBOL or Java/JSP target)
  • Generic IGYWCL JCL template — not per-program
  • CICS transaction table in deployment guide
  • Reference data SQL + security roles table
  • Happy-path and negative test checklist
mf/docs/ — Hand-written COBOL deployment (05-MF-BUILD-DEPLOY)
  • Full multi-step JCL: DLISDB2 → DLISBMS → DLISCOMP → DLISBIND → DLISCSD
  • Named PROCs: DLISCLNK (DB2 precompile + COBOL compile + link-edit), DLISBASM (BMS 2-pass assembly)
  • Per-program DB2 BIND PACKAGE + BIND PLAN(DLISPLAN)
  • DFHCSDUP CSD install with DLISGRP / DLISLIST
  • DB2ENTRY DLISDB2E configuration (thread limit, wait policy, rollback behaviour)
  • Step-by-step re-compile/NEWCOPY/PHASEIN procedure
  • COND code logic explained per step
