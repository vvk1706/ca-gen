4. ACTION BLOCKS  (src/action-blocks/)
---------------------------------------
9 Action Blocks with full action diagram logic:

  AB-CREATE-CANDIDATE.ACB
    - Validate & create candidate (duplicate ID check, DOB validation)

  AB-CREATE-APPLICATION.ACB
    - Create application with license type selection (L/P/O)
    - Checks for existing active application

  AB-CHECK-ELIGIBILITY.ACB
    - Age check per license type:
        Learner >= 16, Probation >= 17, Open >= 18
    - Upgrade path enforcement: L -> P -> O
    - Records Pass/Fail result on application

  AB-CHECK-HISTORY.ACB
    - Checks active suspension or disqualification
    - Tallies total demerit points (threshold: 12)
    - Identifies unpaid fines
    - Records Pass/Fail result on application

  AB-PROCESS-PAYMENT.ACB
    - Looks up fee schedule per license type
    - Records payment with method and reference
    - Generates receipt number
    - Updates application payment status

  AB-RECORD-APPROVAL-1.ACB
    - Validates level-1 authority user and license type authorisation
    - Records Approve or Reject decision
    - Advances or closes application accordingly

  AB-RECORD-APPROVAL-2.ACB
    - Validates level-2 authority user
    - Enforces DIFFERENT authority from first approver
    - Records Approve or Reject decision
    - On approve: sets status AP (ready to issue)

  AB-ISSUE-LICENSE.ACB
    - Full pre-issue gate check (all steps must be complete)
    - Generates unique license number
    - Calculates expiry: Learner=1yr, Probation=2yrs, Open=5yrs
    - Creates ISSUED-LICENSE record
    - Updates application status to IS=Issued

  AB-INQUIRE-APPLICATION-STATUS.ACB
    - Returns full end-to-end status with human-readable description
    - Returns license number if already issued

KEY BUSINESS RULES IMPLEMENTED
================================
  1. License types: L=Learner, P=Probation, O=Open
  2. Minimum age: Learner=16, Probation=17, Open=18
  3. Upgrade path enforced: must hold L before P, must hold P before O
  4. Eligibility check must pass before history check
  5. History check must pass before payment
  6. Payment must be completed before first approval
  7. First approval must be granted before second approval
  8. Second approver MUST be from a DIFFERENT authority than first approver
  9. All five gates (eligibility, history, payment, auth1, auth2) must be
     satisfied before license can be issued
 10. License validity: Learner=1yr, Probation=2yrs, Open=5yrs
 11. History disqualifiers: active suspension, demerit>12, unpaid fines
